Three kinds of money

USDT

Tether’s dollar on BSC. It stays locked in the vault while it is on the Credits side.

csUSDT

“Credits Bridged USDT”. Created 1 for 1 when USDT enters the vault, destroyed when it leaves. Not issued by Tether.

CS

The Credits coin. It pays every Credits transaction fee, and it is traded against csUSDT.

The rule that always holds: csUSDT in circulation + unpaid withdrawals ≤ users’ USDT in the vault.

Every relayer checks that rule at every cycle. If it ever breaks, any relayer can stop the bridge.
